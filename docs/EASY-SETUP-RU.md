# Tung Tung Client 1.30.2 — установка

## Сначала выбери систему

- **Mac:** папка `Mac`, архив с окончанием `Mac-1.30.2-Voice-Chat.zip`.
- **Windows:** папка `Windows`, архив с окончанием `Windows-1.30.2-Voice-Chat.zip`.
- **Prism Launcher:** папка `Prism`, импортируй ZIP как новый экземпляр.

Архивы для разных систем не нужно устанавливать одновременно.

## Mac

1. Распакуй Mac ZIP. Закрой старый Tung Tung Client через ⌘Q.
2. Перемести `Tung Tung Client.app` в «Программы», замени старую копию.
3. Открой приложение. Внизу должно быть **macOS 1.30.2**.
4. Закрой Minecraft через Quit Game и Launcher через ⌘Q.
5. Открой **Control center → Choose Minecraft Folder**. Для официального лаунчера выбери `~/Library/Application Support/minecraft`.
6. Нажми **Install Fabric Core** и дождись результата.
7. В Minecraft Launcher выбери **Tung Tung Client 26.3**, нажми Play и зайди в мир.
8. Вернись в Tung Tung Client: состояние должно смениться с `CORE DISCONNECTED` на подключённое.

Для Prism выбирай папку `minecraft` именно нужного экземпляра через его меню Minecraft Folder. Не смешивай её с папкой официального лаунчера.

## Windows

Требуется Windows 10/11 x64, .NET Framework 4.8 и Microsoft WebView2. Windows-приложение собрано на Mac; запуск на настоящей Windows в этом релизе не проверен.

1. Распакуй **весь** Windows ZIP. Не запускай EXE прямо из архива.
2. Открой `START-TUNG-TUNG-CLIENT.cmd` или `Tung-Tung-Client.exe`. Все соседние папки и DLL должны оставаться рядом.
3. Закрой Minecraft и Minecraft Launcher.
4. В **Control center** выбери `%APPDATA%\.minecraft`, затем **Install Fabric Core**.
5. Открой Minecraft Launcher → **Tung Tung Client 26.3** → Play → зайди в мир.
6. Проверь подключение в Tung Tung Client. Если отсутствует WebView2, установи его с помощью включённого Microsoft-инсталлятора.

## Карты / map art

В **Texture Packs → Map Art** есть две отдельные карточки:

- **Client Maps** — сохраняет полученные от сервера изображения карт отдельно для каждого сервера.
- **Map in Slot** — рисует содержимое карты в её ячейке инвентаря.

Оба модуля включены по умолчанию в ядре. Их кнопки становятся доступны после подключения игры. Шестерёнка карточки открывает настройки и назначение клавиши. Это моды, а не resource pack. Карта, данные которой сервер ещё не прислал, не появится сама.

## Voice Chat

Нажми **V в Minecraft**, выбери микрофон и пройди его тест. На Mac разреши микрофон запрашивающему игровому приложению. На сервере тоже должен работать совместимый Simple Voice Chat.

## Если ничего не изменилось

- В приложении должна быть версия **1.30.2**, а не 1.29.7. Закрой старую копию через ⌘Q и открой новую из «Программ».
- После установки ядра обязательно полностью перезапусти игру: уже работающий Minecraft не перечитывает JAR.
- `CORE DISCONNECTED`: проверь выбранный профиль и папку Minecraft. Само открытие лаунчера не подключает ядро.
- `Incompatible client … 26.2`: сервер отвергает протокол 26.3. При установленном ViaFabricPlus выбери поддерживаемый сервером протокол в Multiplayer; если адаптера нет, потребуется подходящий профиль. Переключатель map art не исправляет протокол соединения.
- `This server is offline`: проверь адрес сервера. Это сообщение сервера или прокси, а не подтверждение сбоя всех модулей.

## Как обновлять дальше

Скачай следующую версию, закрой клиент, Minecraft и Launcher, замени приложение/папку Windows, снова выполни **Install Fabric Core**, затем перезапусти выбранный профиль. Сверь номер приложения и ядра. Инструкция: [UPDATES.md](UPDATES.md).
