# Hard Crystal and clean MCPVP chat

Open **Arsenal → Hard Crystal**. It reuses the Minecraft end-crystal icon and has its own toggle key in the gear menu. Enabling it turns Auto Crystal off; enabling Auto Crystal turns Hard Crystal off.

1. Hold an end crystal in either hand.
2. Click your configured mouse use button once on obsidian or bedrock, then release.
3. The client waits for a new matching crystal entity from the server, then requests one ordinary attack. Your cursor can stay on obsidian.
4. Wait for the action to finish before the next click. Holding the button never repeats. A rejected attack is not automatically retried.

Normal interaction/attack reach, visibility, existing friend protection and optional self-damage limits apply. Menus, focus loss, death, detached camera, inventory conflicts and world changes cancel pending actions. This module does not disable anti-cheat or guarantee acceptance by any server. Keyboard-bound use is not supported by this physical mouse-click module.

The known message “Your client version (…) is NOT recommended due to interpolation changes that make movement choppy.” is hidden automatically only for the mcpvp.club server family. This is a display filter, not a movement/interpolation fix. Other chat, action-bar messages and server warnings are preserved.

The Mac app no longer embeds a redundant Prism instance ZIP. Mods, map-art support, Simple Voice Chat and texture packs remain included. Download the separate Prism archive if you use Prism Launcher.
