# Friends — 1.36.5

1. Open **Friends** and start typing a Minecraft username. Matching names from the current server and saved friends appear immediately; capitalization does not matter.
2. Click a suggestion, or use **Up / Down → Enter**, to fill the name. Press **ADD FRIEND** to save it. You can also enter an offline username manually.
3. The player's skin face appears on the left of each suggestion and saved friend. Known names also show a face beside the input. Saved offline names load their public Minecraft skin in the background; unavailable skins use the loading placeholder.

Friends' existing aim, attack and blast protections remain independently configurable. Selecting a suggestion only fills the field; it does not send a friend request or add the name until you press Add.

Online server skins are preferred. Offline saved names resolve through the official Mojang profile and Minecraft texture services, with bounded requests and a cache. No lookup runs on every typed character. Suggestions and heads refresh without replacing the active text field or moving its cursor.
