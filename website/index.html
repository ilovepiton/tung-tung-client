    A few things to know.

    Will this install Fabric too?

    Use Control center → Install Fabric Core with Minecraft and Launcher closed. Then choose Tung Tung Client 26.3 in your launcher. Minecraft must already be installed and have been started once.

    Where are the BetterMaceSwap controls?

    Open Arsenal and choose a feature. Enable Auto Stun Slam, hold a mace and right-click a blocking opponent once with a usable axe in your hotbar. It sends an axe attack and queues the native mace follow-up; holding does not repeat. Use the gear button for native trigger and target settings, or assign a module keybind. Gear Up has separate Record Kit and Equip Kit buttons.

    Does every feature work on every server?

    No. The server controls movement, attack results, hidden terrain and voice connectivity. Simple Voice Chat also needs support on the server. This update has automated checks, but the new combo has not yet been verified in a live multiplayer match.

    How do I update the client?

    Click UPDATE in the app header or on a module card. It checks GitHub Releases, downloads and verifies the platform package, and prepares the update. Close Minecraft and its launcher first. The client restarts after its application files are replaced.
